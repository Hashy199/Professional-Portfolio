# Challenge

Create a typing speed test using tkinter module.

# Approach
 
I wanted to make the interface and functionality like this website: https://www.keybr.com . I was able to make the interface much more easily than the previous project as I could remember tkinter functions much better. I successfully brokedwon the main problem into smaller problems like paragraph loading, displaying and tracking each letter typed. I had to use claude help for tkinter text widget and adding tag highlight. 


# Reflection and Room For Improvement

For me highlighting the text and making the restart functionality was challenging. I think I still struggled with placing labels and widgets on the screen. This project has room for improvement as the interface and design can be improved a lot; moreover, the project can have the functionality to track the data and display graph to show the improvement of the typing speed.
